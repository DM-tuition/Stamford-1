# Assets

## The crest — `assets/crest.png`  ← drop your new logo here

The whole site now points at **`assets/crest.png`** (nav, hero, footers, captain
badges, preloader and favicon). Save the new textured/stamped Stamford crest as
exactly `assets/crest.png` and it appears everywhere automatically.

Until that file exists, every crest **falls back to the old `crest.svg`**, so the
site never shows a broken image.

**Tip for the sharpest result:** the nav logo and badges are small (~42px) and the
hero crest sits on a glow. A version with the **background removed** (transparent
shield cut out from the rock texture) will look cleanest at small sizes. If you have
both, use the transparent cut-out as `crest.png`. A square ~512×512 (or taller, the
shield centred) works well.

`crest.svg` is kept as the safety fallback — don't delete it.
