# Drop your photos here

The site auto-detects these and swaps placeholders for real images:

- `daniel.jpg` — Daniel Stevenson portrait (Captain card, Home + Leadership)
- `ayaan.jpg` — Ayaan Siddiqui portrait (Vice Captain card)

If a file is missing, the page falls back to initials automatically (no broken images).

**Gallery:** open `gallery.html` and replace each `<div class="shot">…</div>` placeholder with an
image, e.g. `<div class="shot"><img src="assets/photos/house-shout.jpg" alt="House Shout"></div>`.

Recommended: portraits ~800×1000px, gallery shots ~1200px on the long edge, JPG/WebP.
