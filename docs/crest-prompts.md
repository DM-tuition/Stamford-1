# House crest prompts (ChatGPT image generation)

Goal: Bradbury, Massey and Tatton crests rendered in the **same 3D enamel style** as the Stamford crest (`assets/crest.png`), so all four match as a set.

## How to use

1. Start a new ChatGPT chat (an image-capable model).
2. Attach **two images**: the Stamford crest (`assets/crest.png`, the style reference) **and** the official flat crest for the house you're making (your screenshot, the design reference).
3. Paste that house's prompt below.
4. Do the other two **in the same chat**, attaching the next official crest each time, so the style stays consistent.
5. If something's off, use the fix-up prompt at the bottom.

When they're done, send them back and they'll replace the letter shields on the site (`assets/crest-bradbury.png`, `assets/crest-massey.png`, `assets/crest-tatton.png`).

---

## Bradbury

```
Create a crest for Bradbury house. Image 1 is the STYLE reference (the Stamford crest). Image 2 is the DESIGN reference (the official Bradbury crest). Copy the style of image 1 exactly and the design of image 2 exactly.

STYLE (match image 1):
- Same shield silhouette and proportions as image 1: flat top, sides curving down to a single point.
- Same frame: polished antique-gold double rim with a thin dark keyline inside it, same thickness.
- Cloisonné enamel: every area of colour is a separate glossy enamel panel, divided by thin raised gold wires.
- Coloured enamel is deep, glossy and slightly translucent, with soft marbled cloud swirls and light reflections, like the blue in image 1. White areas are warm ivory/pearl enamel with a faint texture.
- Viewed straight on, no tilt or perspective. Soft studio light from the top left, subtle soft shadow.
- Transparent background PNG (if not possible, plain pure white), portrait 1024x1536, shield centred and filling about 80% of the height.
- No banner, scroll, text, letters, crown, helmet or any decoration outside the shield.

DESIGN (match image 2 exactly, add nothing):
- Field: rich red enamel.
- A broad white chevron across the middle, point upwards, its surface covered in a fine repeating pattern of small raised red fleur-de-lis-style motifs, as in image 2.
- Three black ornamental buckles, exactly as drawn in image 2: two side by side above the chevron, one centred below it. Render them in glossy black enamel outlined in fine raised gold, same shape, size and orientation as image 2.
```
